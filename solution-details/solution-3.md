# **Solution 3 : ระบบปล่อยน้ำแบบ Adaptive เพื่อระบายความร้อนบนทางเดินเท้าและตรอกซอยอย่างมีประสิทธิภาพสูงสุด**

# **Leverage point fit**

\-UHI

# **Function**   

- วัดอุณหภูมิผิวทางเดินเท้าและคอนกรีตซอยแบบ Real-time เพื่อระบุ Thermal Hotspot  
- เก็บ data อุณหภูมิและปริมาณน้ำที่ใช้รายวัน เพื่อวิเคราะห์ประสิทธิภาพและปรับค่าระบบอัตโนมัติ

# **Operation**

**\- Input**

* อุณหภูมิผิวคอนกรีตหรือทางเดินเท้า (IR Surface Temperature Sensor)  
* เวลาแบบ Real-time เพื่อกำหนดช่วงทำงาน 11:00–14:00 น.

**\- Process**

* ตรวจสอบเงื่อนไขก่อนเปิดระบบ อุณหภูมิผิวเกิน 45 °C   
* สั่งเปิด Solenoid Valve เพื่อปล่อยน้ำผ่านหัวฉีด  
* ตรวจสอบข้อมูลซ้ำ แล้วปรับปริมาณน้ำตามสภาพอากาศที่เปลี่ยนไป  
* หยุดระบบเมื่อความชื้นเกินเกณฑ์ที่กำหนด

**\- Output**

* เกิดละอองน้ำบาง ๆ บนผิวทางเดินเท้า เพื่อให้น้ำระเหยและช่วยลดอุณหภูมิผิว

# **Tech stack**

- กล้องวัดความร้อนพื้นถนน (IR Surface Thermometer)  
- ระบบรดน้ำอัตโนมัติ  
- หัวฉีดน้ำ พ่นน้ำออกมาเป็นละอองบางๆ

**Strong point**

- ถ้าทำได้จะสามารถรู้ได้ว่าต้องใช้น้ำเท่าไหร่ในแต่ละช่วงเวลา ไม่สูญเสียน้ำไปกับ Runoff

**Weak point**

- บางจุดในซอยไม่มีแหล่งน้ำสะอดอยู่ใกล้ ต้องต่อท่อ น้ำจากอาคารซึ่งอาจมีข้อจำกัดด้านสิทธิ์การใช้พื้นที่  
- ต้องใช้พื้นที่ในปริมาณมากเพื่อทำให้เกิดผลที่้ตองการ
